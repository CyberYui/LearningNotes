CSS 变量与主题切换

2024-06-05 · CSS 技巧

CSS 变量 (Custom Properties) 允许在 :root 中定义全局变量, 然后在整个页面中使用 var(--variable-name) 引用。 通过 JavaScript 切换 data-theme 属性, 可以实现主题切换。

点击右上角的 "切换主题" 按钮试试!

响应式设计

2024-06-05 · 响应式

本页面使用了移动优先的响应式设计策略:

  • 桌面: Grid 两栏布局 (主内容 + 侧边栏)
  • 平板 (≤768px): 单栏布局, 侧边栏移到底部
