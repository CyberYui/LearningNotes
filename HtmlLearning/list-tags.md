# 列表标签

> 创建有序和无序列表

## 标签列表

### `<ul>`

**作用:** 定义无序列表

**常用场景:**
- 展示项目清单
- 导航菜单
- 不强调顺序的内容

```html
<ul>
  <li>项目一</li>
  <li>项目二</li>
  <li>项目三</li>
</ul>
```

---

### `<ol>`

**作用:** 定义有序列表

**常用场景:**
- 步骤说明
- 排名列表
- 强调顺序的内容

```html
<ol>
  <li>第一步</li>
  <li>第二步</li>
  <li>第三步</li>
</ol>

<!-- 带起始编号 -->
<ol start="5">
  <li>第五项</li>
  <li>第六项</li>
</ol>

<!-- 倒序 -->
<ol reversed>
  <li>第三项</li>
  <li>第二项</li>
  <li>第一项</li>
</ol>
```

---

### `<li>`

**作用:** 定义列表项

**常用场景:**
- 必须包含在 `<ul>` 或 `<ol>` 中
- 可以包含任意内容

```html
<ul>
  <li>文本项</li>
  <li><a href="#">链接项</a></li>
  <li><strong>加粗项</strong></li>
</ul>
```

---

### `<dl>`

**作用:** 定义描述列表

**常用场景:**
- 术语和定义
- FAQ 列表
- 键值对展示

```html
<dl>
  <dt>HTML</dt>
  <dd>超文本标记语言</dd>

  <dt>CSS</dt>
  <dd>层叠样式表</dd>

  <dt>JavaScript</dt>
  <dd>脚本语言</dd>
</dl>
```

---

### `<dt>`

**作用:** 定义描述列表中的术语

**常用场景:**
- 作为 `<dl>` 的子元素
- 通常加粗显示

```html
<dl>
  <dt>术语</dt>
  <dd>术语的描述</dd>
</dl>
```

---

### `<dd>`

**作用:** 定义描述列表中术语的描述

**常用场景:**
- 作为 `<dl>` 的子元素
- 通常缩进显示

```html
<dl>
  <dt>术语</dt>
  <dd>这是术语的详细描述内容。</dd>
</dl>
```

---

### `<menu>`

**作用:** 定义菜单列表

**常用场景:**
- 上下文菜单
- 工具栏
- 与 `<ul>` 类似

```html
<menu>
  <li>菜单项一</li>
  <li>菜单项二</li>
  <li>菜单项三</li>
</menu>
```
