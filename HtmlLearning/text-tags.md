# 文本标签

> 定义文本内容的结构和样式

## 标签列表

### `<h1>` - `<h6>`

**作用:** 定义标题，h1 为最高级，h6 为最低级

**常用场景:**
- 文章标题使用 h1
- 各级小标题使用 h2-h6
- 每个页面最好只有一个 h1

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
```

---

### `<p>`

**作用:** 定义段落

**常用场景:**
- 包裹文本段落
- 浏览器会在段落前后添加空白

```html
<p>这是一个段落。</p>
<p>这是另一个段落。</p>
```

---

### `<span>`

**作用:** 行内元素，用于包裹文本进行样式设置

**常用场景:**
- 为特定文本添加样式
- 不改变文本结构

```html
<p>这是一段文本，其中<span style="color: red;">这几个字</span>是红色的。</p>
```

---

### `<strong>`

**作用:** 表示重要文本，默认加粗

**常用场景:**
- 强调重要内容
- 比 `<b>` 更有语义

```html
<p>请<span>务必</span>注意安全。</p>
```

---

### `<em>`

**作用:** 表示强调文本，默认斜体

**常用场景:**
- 强调语气
- 比 `<i>` 更有语义

```html
<p>这<em>真的</em>很重要。</p>
```

---

### `<br>`

**作用:** 插入换行符

**常用场景:**
- 在段落中强制换行
- 诗歌、地址等

```html
<p>
  第一行<br>
  第二行<br>
  第三行
</p>
```

---

### `<hr>`

**作用:** 插入水平线，表示内容分隔

**常用场景:**
- 分隔不同主题的内容
- 视觉上的分隔线

```html
<p>第一部分内容</p>
<hr>
<p>第二部分内容</p>
```

---

### `<pre>`

**作用:** 预格式化文本，保留空格和换行

**常用场景:**
- 展示代码
- 保留格式的文本

```html
<pre>
  第一行
    第二行（有缩进）
  第三行
</pre>
```

---

### `<code>`

**作用:** 定义代码片段

**常用场景:**
- 行内代码
- 配合 `<pre>` 使用

```html
<p>使用 <code>console.log()</code> 输出内容。</p>

<pre><code>
function hello() {
  console.log('Hello');
}
</code></pre>
```

---

### `<abbr>`

**作用:** 定义缩写

**常用场景:**
- 鼠标悬停显示完整内容
- 提升可访问性

```html
<p>学习 <abbr title="HyperText Markup Language">HTML</abbr> 很重要。</p>
```

---

### `<blockquote>`

**作用:** 定义长引用

**常用场景:**
- 引用其他来源的内容
- 浏览器会缩进显示

```html
<blockquote cite="https://www.example.com">
  这是一段引用的内容。
</blockquote>
```

---

### `<q>`

**作用:** 定义短引用

**常用场景:**
- 行内引用
- 浏览器会自动添加引号

```html
<p>他说：<q>今天天气真好。</q></p>
```

---

### `<cite>`

**作用:** 定义引用来源

**常用场景:**
- 引用书籍、文章等
- 浏览器会斜体显示

```html
<p>这篇文章来自 <cite>《HTML 权威指南》</cite>。</p>
```
